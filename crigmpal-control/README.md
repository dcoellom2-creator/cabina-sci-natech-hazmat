# Control Conversatorio CRIGMPAL

Aplicación estática para operar el conversatorio **Conocer el riesgo para decidir y actuar**.

## Funciones

- Prompter operativo por bloque.
- Cronograma de Día 1 y Día 2.
- Alarmas visuales y sonoras a 5 minutos, 2 minutos y fin de bloque.
- Tarjetas de ponentes: Kervin, Daniel, Patricio y Xavier.
- Control de calidad y registro local de incidentes.
- Banco de ideas para clips de 30–60 segundos.
- Ruta de servicios: diagnóstico, asesoría, capacitación e implementación.

El contenido del conversatorio genera la necesidad; el catálogo aparece al final como ruta de acompañamiento técnico.
